# LAB 02

## Task 1: Create more complex behaviour of the application

Combine functionality from previous tasks and create more complex behaviour:

   1. If there is no face in the image from the camera, display some preloaded static image (aka sreen-lock) and do not display image from the camera

   2. If there is exactly one detected face, track some object (by luma, chroma, or other methods...)

   3. If there are more than one face detected (someone is peeking over your shoulder to your screen), display non-camera image with warning

   4. Measure and display application (function) performance: create (modify) FPS meter class, show FPS
